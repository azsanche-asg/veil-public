# VEIL

A browser tactics game about reconnaissance, concealed positions and simultaneous orders.

[VEIL at Burrito’s Labs](https://veil.burritoslabs.com/)

## Technology

Browser-local rules and AI, IndexedDB, Cloudflare Workers and Durable Objects for online duels.

## Architecture

The solo game resolves tactical orders locally. Optional online duels use a separate room service to coordinate players and exchanges of game state.

## Product behavior

Solo progress can be exported, imported and played offline after a successful load on supported browsers. Online duels use a connection.
